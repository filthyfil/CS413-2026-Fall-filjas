CAS CS 413

(Agentic) Software Engineering

Fall 2026

Engineering software, together.

Learn the principles and practices of building medium- and large-scale software systems, from requirements and design to testing, evolution, and team collaboration.

A semester-long team project puts these ideas into practice by building a compiler for a small functional programming language.
